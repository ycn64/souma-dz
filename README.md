# 🇩🇿 Algerian Car Price Estimator

A machine-learning project for estimating used-car asking prices in the Algerian market.

The goal of this project is to build a data-driven estimator that takes vehicle characteristics such as model, year, mileage, fuel type, gearbox, and location, and predicts an estimated asking price in Algerian dinars (DA).

> **Note:** The target variable represents the seller's asking price, not the final price at which a vehicle was sold.

## 🎯 Project Goal

Used-car prices in Algeria can vary significantly depending on the vehicle, its age, mileage, specifications, location, and other characteristics.

This project explores whether these factors can be used to build a useful machine-learning model for estimating used-car prices.
